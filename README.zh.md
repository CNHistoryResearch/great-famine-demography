# 1959–61年中国大饥荒死亡人数研究

一个开放、分版本的研究项目，研究大跃进饥荒（三年困难时期）的死亡人数。任何人都可以提交文献、数据、口述证言、
研究或问题。每份提交都要经过自动质量关卡和人工审核，与已有资料逐一对照核算，再进入研究周期，生成下一版
中英文报告。

[English](README.md)

## 当前结论（报告 v1.0，2026年11月）

| | 估计 |
|---|---|
| **超额死亡**（1958年年中至1963年年中） | **约3100万**（可辩护区间2200万–4000万） |
| 仅1959–61三个日历年 | 约2700万 |
| 由官方登记死亡推出 | 1400万–1600万：只是下限，户籍登记只记录了约60%的死亡 |
| 少生或推迟出生 | 总计约3600万，扣除1962–63年补偿性生育后净约2800万（不是死亡） |

完整报告：[中文](reports/v1.0/report_zh.md) · [English](reports/v1.0/report_en.md) ·
PDF 见 [`reports/v1.0/pdf/`](reports/v1.0/pdf/) 和 [Releases](../../releases) 页面。

已发表估计从1700万到4500万不等，差异几乎全部来自两个假设：1953年与1964年普查的相对完整程度，以及“正常”
死亡率应取多高。报告解释了这两点，核查了每一个主要估计，并追溯了这些数字最初如何泄露、又如何被争论。

## 项目如何运作

1. **提交**：通过[议题表单](../../issues/new/choose)提交资料、数据、证言、研究或更正。机器人会把它转成一个带
   `manifest.yaml` 的拉取请求。
2. **质量关卡**自动运行：结构（G0）、来源与网页存档（G1）、可核查性（G2）、新颖性（G3）；之后由维护者审核
   （G4），合并即采纳。详见 [docs/quality-gates.md](docs/quality-gates.md)。
3. **对照核算**：把登记库和已采纳提交中的每个数字按“同一口径、同一地点、重叠时期”比较，分歧进入研究队列。
4. **问题**先自动分拣（查重、是否在范围内），再由维护者决定是否采纳，采纳的问题列入
   [`questions/questions.yaml`](questions/questions.yaml)，在下一版报告中回答。
5. **研究周期**：积累到一定数量后，工作流会整理研究资料包，由 Claude 进行深入研究、重跑模型、起草下一版中英文
   报告，以拉取请求形式提交给人工审核。
6. **发布**：合并后的报告自动生成 PDF 和逐页图片，作为 GitHub Release 发布。

## 参与须知

- **议题和拉取请求都是公开的。** 不需要真实姓名；请勿写入联系方式或可识别在世私人的信息。
- 提交口述证言前，请务必阅读[口述证言政策](docs/testimony-policy.md)，其中说明了更安全的提交方式。
- 每个数字都要有出处；网页来源尽量附上存档链接（web.archive.org 或 archive.ph），没有的话机器人会尝试创建。

## 原则

- **证据优先于立场。** 高估计与低估计接受同样严格的审查；分歧要解释，而不是取平均。
- **口径要分清。** 超额死亡、饿死、总死亡与少生从不混用。
- **机器起草，人来决定。** 自动研究只会生成拉取请求，绝不直接改动 `main` 分支。
